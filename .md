# HTML (HyperText Markup Language)
   > It is a language used to create the basic structure of a web page.
   > Ex: it is like the frame of a car — it defines the basic structure .

# CSS (Cascading Style Sheets)
   > It is a language used to style and design a web page.
   > example: CSS is the paint and color i.e look of the car.

# JavaScript (JS)
   > It is a programming language used to make web pages interactive and dynamic. It adds functionality to the page.

   > example: It is like the engine and controls that make it move and respond.

# HTML = car’s body, CSS = car’s design, JavaScript = car’s engine and controls that make it move and respond.

# Tags : 
> <html> : The main wrapper tag of the entire webpage.
> <head> : It Contains page info and connects .css .js files.
> <body> : It Contains everything that is visible on the webpage.The area where we code.

# Block Level Tags :
   > Always starts in new line.
   > It takes full width of screen.
   > Ex:<p></p>,<h></h> etc.
# Inline Tags
   > Always starts in same line.
   > It takes required space only.
   > Ex : <span></span>,<strong></strong> etc.

>> _blank : to open in new tab .
>> <div> is a block-level tag used to divide or group content into sections. It is also called as container tag. 

# Semantic tags → Tags that tells the meaning of the content.
   > Example:`<header>` = Header, `<footer>` = Footer.

# Attribute → Tag ko extra information deta hai. 
   > Example: `<img src="car.jpg">` → `src` is an attribute.
   
  >>>`<img src="car.jpg">`
   >`img` → Browser ko batata hai image dikhani hai.
   >`src="car.jpg"` → Browser ko extra information deta hai ki image kahan se leni hai.
   > Isliye `src` ek attribute hai.

# Property → JavaScript se element ki value ko access/change karta hai.
   > Example: `img.src` → `src` is a property.

# 3 गोल्डन रूल्स :
   
   > 1. लेआउट: position: absolute की जगह हमेशा Flexbox या Grid का इस्तेमाल करें।

   > 2. दूरी: margin की जगह हमेशा padding या gap का इस्तेमाल करें।

   > 3. चौड़ाई: फिक्स पिक्सल (px) की जगह हमेशा प्रतिशत (%) का इस्तेमाल करें।

>  display: flex;

   > 1. display: flex; -> चीजों को एक सीधी लाइन में सेट करने के लिए।

   > 2. flex-direction: column; -> सभी चीजों को एक के नीचे एक खड़ा करने के लिए।

   > 3. justify-content: center; -> चीजों को ऊपर-नीचे (या सीधे खड़े में) बिल्कुल बीच में लाने के लिए।

   > 4. justify-content: space-between; -> एक चीज को बिल्कुल लेफ्ट और दूसरी को बिल्कुल राइट में भेजने के लिए।

   > 5. align-items: center; -> चीजों को दाएं-बाएं से बिल्कुल बीच (Center) में लॉक करने के लिए।

   > 6. gap: 25px; -> बिना मार्जिन के सभी चीजों के बीच बराबर जगह छोड़ने के लिए।

   > 7. height: auto; -> स्क्रीन के हिसाब से डिब्बे की ऊंचाई अपने आप सेट करने के लिए।

   > 8. padding: 40px 15px; -> डिब्बे के अंदर बॉर्डर से थोड़ी खाली जगह बनाने के लिए।

   > 9. box-sizing: border-box; -> पैडिंग और बॉर्डर जोड़ने पर भी डिब्बे का साइज फिक्स रखने के लिए।

# Variable : 
   > A variable is like a container used to hold data.

   >> let : let is a variable that allows you to change its value later.
      > let score = 0;   // starts at 0
      > score = 5;       // changed to 5!
   
   > const : const is a variable that does NOT allow you to change its value later.
      > const birthYear = 2005; // set forever
      > birthYear = 2006;// ERROR! JavaScript will stop you.

# A Data Types : 
   > It is simply the category of data (like a number or a word) that you store in your code.

# different data types : 

   > Primitive Data Types 
      > (Simple, holds a single value)

   > Non-Primitive Data Types 
      >(Complex, holds multiple values)

# Primitive Data Types (Simple) 
 >> typeof tells you the data type of any variable.
   > let age = 25;
   > console.log(typeof age); // Output: "number"
   > let name ="Teena";
   > console.log(typeof name); // Output: "string"
   > let isHappy = true;
   > console.log(typeof isHappy); // Output: "boolean"

   > Number: 
      > Any mathematical number (whole numbers or decimals).
      > let score = 98; let price = 19.99;

   > String: 
     > Any text It must always be wrapped in quotes ("",'').
     > let name ="Teena" ; let city= "karnataka";

   > Boolean:
      > A true or false value. Used for making decisions.
      > let isCodingFun = true;let isChaining = false;
      
   > Undefined: 
      > A variable that has been created but has no value given to it yet.
      > let age; // JavaScript automatically sets this to undefined

   > Null: 
      > Represents an intentional empty value. You are explicitly saying, "this is empty."
      > let userLocation = null; 

# 2. Non-Primitive Data Types (Complex)
   > Object: 
    > It is Used to store a collection of data in key: value pairs. 
    > let user = {
      name: "Reena",
      age: 21,
      isLoggedIn: true
      };

   > Array:
      > A list of data stored inside square brackets [].
      > let colors = ["red", "green", "blue"];
